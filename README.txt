IMPORTANT LIMITATIONS
- SOS creates a local demo event only. It does not call police or send SMS/messages.
- Location is requested from the browser and displayed locally; it is not transmitted.
- Child protection is a guardian check-in note demo, not live tracking.
- Use fictional data in the hackathon demonstration.
- This prototype is not a substitute for real emergency services.
